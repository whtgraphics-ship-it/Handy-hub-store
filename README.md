# Handy Hub Storefront

A responsive green-themed Handy Hub product catalogue for kitchen appliances, watches, dresses and kids' toys, using the supplied brand assets.

## Included
- Responsive storefront and product grid
- Search, category filters and price sorting
- Product badges: Trending, New arrival, Out of stock
- Demo admin panel: add, edit, delete products, upload product images
- Browser localStorage persistence

## Run locally
Open `index.html` in a modern browser. For best results, serve the folder with a local static server or deploy it to a static hosting service.

## Important before public launch
This is a front-end prototype, not a production-ready commerce backend.
- The demo PIN is visible in the JavaScript and is NOT secure authentication.
- Products are saved only in the current browser's localStorage; they do not sync between devices or customers.
- No real checkout, order management, payment gateway, supplier API, inventory sync, or delivery integration is included.
- The WhatsApp enquiry button opens a pre-filled message but does not place an order.
- Replace the demo login with server-side authentication and role permissions.
- Store products/images/orders in a database or commerce backend.
- Add a verified business WhatsApp number, policies, shipping/returns information, privacy notice, and payment integration before accepting payments.
- Confirm your chosen dropshipping/reselling model and local legal/tax requirements before selling, especially if operating from Saudi Arabia and fulfilling to India.
